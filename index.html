가사 전체의 라임을
발음으로 분석하다.

한국어와 영어가 섞인 랩 가사에서 행 끝뿐 아니라 단어 내부와 여러 단어에 걸친 발음 패턴을 찾아냅니다. 분석 결과는 발음 기반 후보이며 실제 발음과 퍼포먼스에 따라 달라질 수 있습니다.

01 / 가사 입력

가사를 입력하거나 테스트 벌스를 불러와 분석을 시작하세요.

02 / 라임 맵

같은 색 밑줄은 음절 구간 비교로 발견한 라임 후보 그룹입니다.

분석 결과가 여기에 표시됩니다.
—라임 그룹
—연결 구간
—음절 수(근사)

03 / 라임 상세 분석

유사도는 모음·종성·초성의 일치 정도를 계산한 휴리스틱 점수이며, 실제 라임일 확률은 아닙니다.

먼저 가사를 분석하세요.

04 / 플로우 스케치

행별 음절 밀도와 텍스트 길이를 비교합니다.

텍스트만으로 실제 비트의 박자 위치, 강세, 쉼, 당김음을 판별할 수 없습니다. 실제 플로우 분석에는 오디오가 필요합니다.

05 / 발음 확인

한국어는 초성·중성·종성으로 분해합니다. 영어는 내장 발음 사전과 근사 변환을 사용합니다.

분석 후 발음 정보가 표시됩니다.
